Privacy policy

Applies to PS Workspace for Windows, including the Microsoft Store package. Last updated: 3 November 2026.

The short version: PS Workspace does not collect, transmit or store information about you. There is no account, no analytics, no telemetry, no crash reporting, no update ping and no advertising. Your documents stay on your machine. The only network traffic the app makes is the AI and search traffic you start, sent from the app directly to the provider you configured, using your own key.

1. What we do not collect

All usage reporting has been removed from the product rather than switched off, so no configuration can turn it back on. Specifically, the app has no code path that sends any of the following anywhere:

  • no analytics SDK, no measurement or reporting endpoint of any kind;
  • no install identifier, device identifier, session identifier or per-launch beacon;
  • no file names, file paths, document content, clipboard content or search terms;
  • no crash dumps, diagnostics, performance data or usage logs;
  • no collection of your name, e-mail address, account identity or location.

The Microsoft Store package writes no activity log about you at all. The command-line tool that ships alongside the desktop app can record the commands it runs into a local file (see section 2); in the Store package that recording is turned off, and in a classic install the file never leaves your machine.

2. What the app stores on your computer

Your documents
Opened and saved through the normal file system, in the folders you choose. The app keeps no server-side copy — there is no service to keep one.
Settings and preferences
In your per-user app-data folder (%APPDATA%\PS Workspace for a classic install; inside the package's own data for the Store package). Theme, language, editor state, AI configuration.
Your AI and search API keys
Stored in ps-secrets.json inside that same folder, sealed with Windows Data Protection (DPAPI) through the operating system's credential store. The file is readable only by your Windows user account on this machine: copying it to another account or another computer leaves it unreadable. Keys are written to disk only when the operating system can seal them; if sealing is unavailable, nothing is written and the key lives only in that session's memory. Keys are never placed in a plain settings file and never written to a log.
The local file index
If you turn on file search, the app builds an index (file-index.db) of the folders you authorised, on your disk. It is never uploaded.
The command-line audit trail (classic installs only)
Outside the Store, the bundled genoffice command-line tool appends each command it runs — including the file paths in its arguments — to ~\.genoffice\cli-audit.jsonl on your own disk, so you can see afterwards what an AI agent touched. It is never transmitted, it rolls over at about 2 MB, and you can delete the folder or set GENOFFICE_AUDIT_LOG=off. The Microsoft Store package disables this log; nothing is written there.

3. When anything leaves your machine — and who sees it

The app runs offline by default. A connection opens only when you use a feature that needs one, and in every case the traffic goes to the service you configured, not to us:

  • AI features (writing, editing, summarising, image generation, analysis): the prompt, plus only the document context you select, is sent directly to the provider you chose — Google Gemini, Anthropic Claude, OpenAI, xAI Grok, or any OpenAI-compatible endpoint you enter. Your own key is attached to that request. No third party sits between you and the provider, and that provider's own terms and privacy policy govern what it does with the text.
  • Keyless web search — off by default, opt-in. If you have no search key of your own and switch on Keyless search in Settings → AI media, your search query text is sent to a shared third-party search backend. Turn it off and no query is ever sent.
  • File-search reranking — off by default, opt-in. If you enable the hosted reranker, short excerpts of the top results from your own index are sent to the reranking endpoint you configured, to order your results better.
  • Markdown image host — off until you configure it. The Markdown editor can upload an image you insert to an image host of your choosing — Amazon S3, GitHub or SM.MS — so the link resolves for readers. The button is Image host settings in the Markdown ribbon, next to Insert image. Nothing is sent until you open it, pick a host and save its credential; with no credential saved the app refuses to upload. Only the one image you chose is sent, to the host you named — never the document around it, and never to us.

We operate no server that receives your content. There is no sign-in, no cloud storage, no sync, no update server and no vendor proxy in the product.

4. Your controls

  • See it. Every byte the app keeps about you is in the folders listed above; you can open, copy or back them up at any time.
  • Switch it off. Each network feature is a labelled toggle in Settings. Removing a stored key takes one click — Remove stored key — and deletes it immediately.
  • Delete it. Uninstall the app and delete its app-data folder; that removes settings, keys, index and any cached data. Nothing is left behind on any server.
  • Ask. Write to pratyush60069@outlook.com. Because we hold no data about you, the answer to almost any such request is that there is nothing to remove — but ask anyway.

5. Artificial intelligence in this app

PS Workspace can generate and edit document content with your own AI provider. Text written by a model is not reviewed or verified by anyone before it appears in your document; you remain responsible for what you publish. If you receive PS Workspace output that is harmful, illegal or otherwise objectionable, report it from inside the app — Settings → AI Model → Report AI output builds a report of the exchange and either copies it to your clipboard or opens it in your mail app, addressed to the contact in section 4. Reports are read by the developer; they are not forwarded to any third party.

The app does not filter or moderate model output on a server, because it does not see your documents. Access control is your file system and your own Windows account.

6. Children

PS Workspace is a general-purpose desktop productivity application and is not directed at children under 13. It collects no personal information from anyone, which is what makes that safe. A parent or school deploying it on a child's device controls the AI providers and keys that device can use.

7. Microsoft Store

When you install from the Microsoft Store, downloading, licensing, updating and refund handling run through your Microsoft account under Microsoft's own terms and privacy statement. That traffic belongs to Microsoft; the developer receives only the package you downloaded, and no usage data about you.

9. Changes to this policy

This page is the policy of record. If the app's data practices change, this page is updated and the date at the top changes with it; the updated page is published before the build that changes behaviour reaches the Store. Continued use of a newer version means the policy stamped on that date applies.

Security, briefly. Keys are sealed with Windows DPAPI and scoped to your user account; nothing sensitive is written to a log or a plain settings file; the renderer that displays untrusted text never receives your keys. No system is unhackable — if you lose your Windows account, treat anything stored under it as exposed, and rotate your API keys with your provider.
